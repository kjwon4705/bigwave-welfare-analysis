공통 변수 상세 설명 (Codebook)

사회조사 2025(사람 측)와 중앙부처 복지서비스(정책 측)를 잇는 공통 변수 19개 축과, 정책 측에만 존재해 앱 입력으로 보완하는 6개 축의 생성 기준을 변수별로 기록한 문서. 규칙 엔진(Code/매칭엔진.py)이 두 측을 비교할 때 사용하는 판정식을 함께 명시한다.

  • 사람 측 산출물: 분석/Processed_data/사회조사_표준변수.csv (33,944명 × 47열) — 생성 스크립트 Code/전처리_사회조사.py
  • 정책 측 산출물: 분석/Processed_data/중앙부처복지서비스_변수화.csv (461개 × 52열, 조건 변수 40개) — 생성 스크립트 Code/변수화_중앙부처복지서비스.py
  • 코드 정의 출처: 통계청 사회조사 2025 파일설계서(코드집 포함), 복지로 서비스 상세 페이지

0. 공통 규약

0.1 정책 측 범주형 코딩 (0 / 1 / 2)

정책 측의 대상·조건 변수는 모두 같은 3값 체계를 쓴다. 변수 X에 대해:

코드 의미 예 (X = 장애인)
0 X에 해당하면 받을 수 없음 (배제 사유) 장애인은 받을 수 없음 — 실제로는 거의 빈 코드
1 X와 무관하게 받을 수 있음 (기본값) 장애인도 받을 수 있음
2 X에 해당해야만 받을 수 있음 (전용·필수) 장애인만 받을 수 있음

생애주기 변수는 0의 의미가 실질적으로 채워지는 유일한 그룹이다(생애주기는 상호배타적이므로 "노년 전용 = 청년 불가"가 성립). 대상 변수(장애인·저소득 등)는 자격 사유이지 배제 사유가 아니어서 0이 거의 비어 있고, 수급자 변수만 "수급자 제외" 명시 사업 6건에서 0을 쓴다.

0.2 사람 측 코딩

사람 측 변수는 대부분 관측값(수치) 또는 0/1 플래그다. 1 = 해당, 0 = 비해당, NaN = 해당 문항 비대상자(예: 60세 미만의 생활비마련방법).

0.3 규칙 엔진의 3값 논리

각 조건의 판정 결과는 1(충족) / 0(위반) / NaN(현재 데이터로 판정 불가)이다.

  • AND(조건들): 하나라도 0 → 0 / 0은 없고 NaN 있음 → NaN / 전부 1 → 1
  • OR(대안들): 하나라도 1 → 1 / 1은 없고 NaN 있음 → NaN / 전부 0 → 0

정책 최종 자격 Y = AND(모든 조건). 같은 축에서 여러 변수가 2이면 OR 그룹으로 묶는다(예: 수급자=2 & 차상위=2 → "수급자 또는 차상위"). 관대 필터 원칙: NaN은 절대 제외하지 않는다 — 확실히 위반(0)일 때만 탈락시킨다.

0.4 proxy(근사) 표시

사람 측에서 정확히 관측되지 않아 대체 변수로 근사한 축은 아래 설명에 ⚠️로 표시했다. 규칙 엔진은 이런 축이 쓰인 정책을 Tier B(근사 판정)로 분류하고, 완전 판정 정책만 Tier A로 둔다.

1. 연령

정의 — 신청자 본인(또는 자녀 대상 정책이면 자녀)의 만 나이가 정책의 연령 범위에 드는가.

사회조사 생성 기준 - 원변수: 만연령 (정수, 13~105세; 사회조사는 만 13세 이상만 조사) - 변환: 없음. 연령 컬럼으로 그대로 사용 - 한계: 12세 이하가 표본에 없어 "자녀 나이" 판정은 13~18세 자녀만 관측된다(→ §14)

정책 생성 기준 — 변수 3개 - 연령필요 (0/1/2, 단 의미가 다름): 0 = 연령 조건 없음 / 1 = 생애주기 태그로 근사한 연령 / 2 = 선정기준 원문에 명시된 연령 - 최소연령, 최대연령 (숫자): 연령필요가 1·2일 때만 값 존재 - 추출 규칙(원문 = 지원대상 상세 + 선정기준): - "만 X세 이상" → 하한 X / "X세 초과" → 하한 X+1 / "X세 이하" → 상한 X / "X세 미만" → 상한 X−1 / "X~Y세" → 하한 X·상한 Y - 여러 값이 나오면 관대하게 하한은 최솟값, 상한은 최댓값 - 원문에 숫자가 없으면 생애주기 태그를 범위로 변환(§2의 경계표) → 연령필요=1 - 하한 > 상한으로 뒤집힌 17건(OR 구조 "65세 이상 또는 65세 미만 치매환자", 타인 연령 혼입 "65세 이상 부모 + 18세 미만 자녀")은 판정 불능으로 보고 연령필요=0으로 무효화 - 분포: 0 = 144개, 1 = 168개, 2 = 149개. 하한 최빈값 19세(청년), 상한 최빈값은 없음(120 = 상한 없음 표기)

매칭 규칙 — 연령필요 ∈ {1,2}이면 최소연령 ≤ 나이 ≤ 최대연령 → 1/0. 자녀 대상 정책(자녀여부=2)은 본인 나이가 아니라 자녀 나이에 적용(§14). 연령필요=0이면 판정 생략(1).

2. 생애주기

정의 — 나이를 6단계 구간으로 묶은 범주. 양측 공통 경계:

구간 연령 비고
영유아 0~5세 복지로 태그 체계 준용
아동 6~12세
청소년 13~18세
청년 19~34세 청년기본법 기준
중장년 35~64세
노년 65세 이상
임신·출산 (연령 아님) 상태 태그 연령 근사 시 19~49세

사회조사 생성 기준 — 생애주기 = 만연령을 위 경계로 구간화(pd.cut). 13세 이상만 있어 값은 청소년·청년·중장년·노년 4종(가중 6.0 / 21.5 / 51.0 / 21.5%).

정책 생성 기준 — 복지로 생애주기 태그(쉼표 구분, 예: "청년, 중장년")를 7개 변수 생애주기_영유아 … 생애주기_임신출산으로 전개: - 태그 미기재(153개) → 모든 변수 1 (제한 없음 = 누구나 받을 수 있음) - 해당 태그 포함 & 다른 태그 병기 → 1 / 해당 태그 단독 → 2 / 다른 태그만 → 0 - 분포(0 / 1 / 2): 영유아 239/210/12, 아동 211/243/7, 청소년 191/259/11, 청년 143/301/17, 중장년 168/291/2, 노년 165/270/26, 임신출산 269/181/11

매칭 규칙 — 판정에는 쓰지 않는다(연령 변수가 담당, 같은 축의 이중 필터 방지). 분류·표시·통계 집계용. 임신출산=2는 남성 → 0, 여성 → NaN(임신 여부 미관측).

3. 성별

정의 — 여성 전용 정책(여성 창업지원, 산모 지원 등) 판정.

사회조사 생성 기준 — 원변수 성별코드(1 남 / 2 여) → 성별 = "남"/"여".

정책 생성 기준 — 별도 변수 없이 규칙 엔진 내부에서 서비스명에 여성|임산부|산모|모성이 포함되고 남녀가 포함되지 않으면 여성 전용으로 판정.

매칭 규칙 — 여성 전용이면 성별=여 → 1, 남 → 0.

4. 장애인

정의 — 등록장애인 여부 / 장애인 전용 정책 여부.

사회조사 생성 기준 - 원변수: 장애인복지카드_소유여부 (1 가지고 있다 / 2 가지고 있지 않다) → 장애인 = 1/0. 소유 2,052명(표본 6.0%, 가중 4.9%) - 보조 변수: 활동제약 6문항(보기·듣기·계단 오르기·기억/집중·자기관리·의사소통, 각 1 전혀 어렵지 않다 ~ 4 전혀 할 수 없다)에서 3(상당히 어렵다) 이상이면 해당 항목 플래그 → 활동제약_보기 등 6개, 하나라도 1이면 활동제약_있음(2,451명, 6.1%). 미등록 기능제한을 포착하는 용도이며 자격 판정에는 쓰지 않음

정책 생성 기준 — 장애인 (0/1/2) - 2(장애인만): 서비스명에 '장애' 포함 또는 지원대상 태그가 '장애인' 단독인 경우 — 75개 - 1(장애인도 가능): 그 외 386개. 여기에는 "수급자·장애인·국가유공자 등" 식으로 장애인이 여러 대상 중 하나(OR)로 언급된 79개가 포함되며, 이들은 비장애인도 받을 수 있어 2로 올리지 않는다 - 0: 장애를 이유로 배제하는 정책은 없어 0개

매칭 규칙 — 장애인=2이면 사람 장애인=1 → 1, 0 → 0. 단 자녀 대상 정책(자녀여부=2, 예: 장애아보육료)이면 자녀의 장애가 기준이라 NaN.

5. 소득 수준 (기준중위소득 %)

정의 — 가구소득이 가구원수별 기준중위소득의 몇 %인지 / 정책의 소득 상한.

사회조사 생성 기준 ⚠️ 근사 - 원변수: 가구소득코드 (월평균 가구소득 9구간: 1 = 100만 미만, 2 = 100~200만, …, 8 = 700~800만, 9 = 800만 이상). 가구 대표 1명만 응답 → 가구일련번호로 가구원 전원에 전파(groupby.transform('max')) - 가구원수: 분류코드_가구원수 (061 1인 / 062 2인 / 063 3인 / 064 4인 이상) → 1/2/3/4 - 변환: 중위소득%_근사 = 구간 중간값 ÷ 가구원수별 2025년 기준중위소득 × 100 - 구간 중간값: 1구간 50만, 2~8구간 각 구간 중앙(150·250·…·750만), 9구간 900만 - 기준중위소득(월): 1인 2,392,013 / 2인 3,932,658 / 3인 5,025,353 / 4인 6,097,773원 (4인 이상은 4인 기준 — 대가족 소득비율 과대, 저소득 과소 방향) - 파생 플래그: 중위소득50이하, 75이하, 100이하, 150이하 - 한계: 자기보고 구간 응답이라 하향 편향 — 중위소득 50% 이하 비율이 20.4%(가중)로 가계동향조사(10.6%)의 약 2배. 집단 간 상대 비교에는 유효하나 절대 규모 해석은 주의

정책 생성 기준 — 소득상한_중위소득% (숫자, NaN = 명시 상한 없음) - 원문에서 정규식 중위\s*소득(의)?\s*(\d{2,3})\s*%로 % 추출, 여러 값이면 최댓값(세부 대상별 기준이 다를 때 가장 관대한 경로) - 68개 정책 보유. 분포: 50%(16), 100%(11), 75%(8), 120%(6), 150%(4), 200%(3), 32/40/45/48/52/60/63/65/70/72/80/125/160/180/250% 등 - 보조 변수 저소득 (0/1/2): 지원대상 태그 '저소득' 단독 또는 서비스명 '저소득' → 2 (65개). 기준선을 담지 않는 태그 신호이므로 단독으로 제외 판정하지 않음. 저소득=2인데 % 상한이 없으면 관대 상한 100%를 proxy로 사용

매칭 규칙 — 상한이 있으면 중위소득%_근사 ≤ 상한 → 1/0 (proxy → Tier B). 수급자·차상위 대안 경로와 OR로 묶임(§6).

6. 수급자·차상위

정의 — 국민기초생활보장 수급자(생계·의료·주거·교육급여) 및 차상위계층(중위소득 50% 이하 비수급) 자격.

사회조사 생성 기준 ⚠️ 근사(60세 이상만) - 사회조사에는 수급 자격 변수가 없음(337개 문항 검색 결과 0건) - 대체: 생활비마련방법코드 (만 60세 이상에게만 질문; 1 본인·배우자 / 2 자녀·친척 / 3 정부 및 사회단체 지원 / 4 기타) → 수급근사_60세이상 = 3이면 1, 1·2·4면 0, 60세 미만(미응답)은 NaN - 응답자 12,800명 중 코드3 1,448명(11.3%). 이들의 90%가 소득 1~2구간이라 수급층과 겹치지만 기초연금 수급도 포함되어 과대 가능 - 60세 미만은 판정 불가 → 앱 직접 입력 항목

정책 생성 기준 — 변수 3개 - 수급자 (0/1/2): 원문에 기초생활|수급자|수급권자|생계급여|의료급여|주거급여|교육급여 언급 & % 상한 없음 → 2 (99개). 수급자.{0,10}(제외|아닌)|비수급 명시 → 0 (6개, 차상위 전용 등). 그 외 1 - 차상위 (0/1/2): 차상위 언급 & % 상한 없음 → 2 (54개) - 수급자차상위 (통합, 0/1/2): 둘 중 하나 언급 & % 상한 없음 → 2 (84개) - % 상한이 함께 있으면(31개) OR 구조로 보아 1 유지 — 비수급자도 %로 통과 가능 - 수급자·차상위 양쪽 2인 41개는 OR 그룹

매칭 규칙 — 소득 축 OR 그룹: (% 상한 충족) OR (수급근사=1). 60세 미만은 NaN → 관대 유지. 수급자=0 정책은 수급근사=1인 사람 → 0.

7. 거주지역

정의 — 거주 시도 / 정책의 지역 제한.

사회조사 생성 기준 - 원변수: 행정구역시도코드 (11 서울, 21 부산, 22 대구, 23 인천, 24 광주, 25 대전, 26 울산, 29 세종, 31 경기, 32 강원, 33 충북, 34 충남, 35 전북, 36 전남, 37 경북, 38 경남, 39 제주) → 시도 명칭 - 보조: 분류코드_동부읍면부구분코드 → 도시여부 - 한계: 시군구 없음(공공용 마이크로데이터 제약). 지자체 서비스 매칭은 앱 입력 필요

정책 생성 기준 — 거주지역 (0/1/2) + 거주지역_상세 - 원문+서비스명에서 시도명 17종과 지역유형(농어촌|읍·면|도서지역|벽지|접경지역) 탐지 - 오탐 제거: "무주택세대구성원"의 '대구' → (?<!세)대구(?!성) lookaround로 배제 - 0 = 언급 없음(전국, 430개) / 1 = 언급 있으나 차등·특례·우선(25개: 긴급복지 산불특별법 지역 특례, 기초연금 농어촌 조항 등) / 2 = 특정 지역 거주자만(6개: 한국형 상병수당 시범, 고혈압·당뇨 등록관리 시범, 권역재활병원, 도서민 여객선 운임, 농어촌 기본소득 시범, 경남동행론) — 2는 원문 검증 후 서비스명 기준으로 지정 - 거주지역_상세: 1·2일 때 탐지된 시도명·지역유형을 쉼표로 나열

매칭 규칙 — 거주지역=2이면 시도 ∈ 상세 → 1/0; 상세가 지역유형(농어촌)이면 도시여부=0 → 1 (proxy). 1은 필터하지 않고 "지역별 조건 상이" 안내.

8. 취업 여부

정의 — 현재 취업 상태 / 정책의 취업·미취업 요구.

사회조사 생성 기준 - 원변수: 지난1주간경제활동여부 (1 하였다 / 2 하지 않았다) → 취업여부 1/0 (가중 60.3%) - 세분: 종사상지위코드 (1 임금근로자 / 2 고용원 있는 자영업자 / 3 고용원 없는 자영업자 / 4 무급가족종사자; 비취업자는 비해당) → 종사상지위, 근로자(=1일 때); 임금근로자구분코드 (1 상용 / 2 임시 / 3 일용) → 임금근로자구분 - 주의: 사회조사 종사상지위 코드는 가계동향조사(1 상용 ~ 7 기타)와 체계가 다름

정책 생성 기준 — 취업여부 (0/1/2, 의미 주의) - 0 = 취업하면 못 받음 (구직자·실업자 전용): 원문에 구직자|실업자|미취업|실직|구직 중 — 21개 - 2 = 취업해야만 받음 (재직자·근로자 대상): 재직자|재직 중|직장인|근로자 — 36개 - 1 = 무관 (404개). 재직자·구직자 모두 언급이면 1 - 오탐 제거: 도시근로자 월평균소득(소득 산정 단위), 상시근로자(기업 규모), 일용근로자 소득, 자활근로자(차상위 유형), 근로자소득은 lookbehind/lookahead로 배제 (청년월세·임대주택·통합문화이용권 오탐 수정)

매칭 규칙 — 2이면 취업여부=1 → 1 / 0이면 취업여부=0 → 1. 취업여부=2 & 자영업=2인 정책(청년미래적금 등)은 "재직자 또는 자영업자" OR.

9. 학생

사회조사 생성 기준 — 재학상태코드 (1 졸업 / 2 수료 / 3 재학 / 4 휴학 / 5 중퇴) → 학생 = 코드 3·4이면 1 (가중 10.4%). 가계동향조사의 수학구분(2 재학 / 5 휴학)과 코드가 다르므로 주의. 결측 835명은 고령(중앙값 82세) → 비재학 처리.

정책 생성 기준 — 학생 (0/1/2): 원문·서비스명에 대학생|재학생|학생 → 2 (47개). 교육비 지원·교육급여처럼 "자녀가 학생"인 정책이 섞여 있음 → 자녀여부=2와 함께 해석.

매칭 규칙 — 학생=2이면 사람 학생 → 1/0. 자녀 대상 정책이면 NaN(자녀의 재학 미관측).

10. 자영업

사회조사 생성 기준 — 종사상지위코드 ∈ {2, 3} → 자영업 = 1 (가중 12.2%).

정책 생성 기준 — 자영업 (0/1/2): 자영업|소상공인|(?<!보험)사업자 → 2 (14개). '보험사업자' 오탐 배제. 환경오염피해 구제급여의 "(오염 원인) 사업자"처럼 남는 오탐은 검수 대상.

매칭 규칙 — 자영업=2이면 사람 자영업 → 1/0 (취업여부=2와 동시면 OR).

11. 1인가구

사회조사 생성 기준 — 분류코드_가구원수 = 061 → 가구원수=1 → 1인가구 = 1 (개인 가중 14.9%; 가구 단위로는 38.8%).

정책 생성 기준 — 1인가구 (0/1/2): 1인\s*가구|독거 → 2 (10개).

매칭 규칙 — 2이면 1인가구 → 1/0.

12. 농어업

사회조사 생성 기준 — 직장산업대분류코드 = 'A'(농업·임업·어업) → 농어업 = 1 (가중 3.0%). 비취업자는 비해당 → 0.

정책 생성 기준 — 농어업 (0/1/2): 농업인|어업인|농어업|임업인|귀농|귀어 → 2 (9개).

매칭 규칙 — 2이면 농어업 → 1/0.

13. 자녀 유무

사회조사 생성 기준 — 자녀유무 (1 있다 / 2 없다) → 자녀있음 1/0 (가중 29.1%); 현재자녀동거여부 → 자녀동거. 자녀 수·연령 문항은 없음.

정책 생성 기준 — 자녀여부 (0/1/2): 2 = 자녀가 있어야만 받음 — ① 원문·서비스명에 자녀|양육|보육|다자녀 또는 ② 생애주기 태그가 미성년(영유아·아동·청소년)만으로 구성(수혜 대상이 아이 = 신청자는 부모). 152개. 다자녀(2~3자녀 이상) 요건은 이 변수에 흡수되며 자녀 수 판정은 하지 않음.

매칭 규칙 — 자녀여부=2이면 자녀있음=1 → 1, 0 → 0. 자녀 대상 정책의 연령·장애·학생 조건은 자녀 기준으로 해석(§1·4·9).

14. 자녀 연령대

사회조사 생성 기준 ⚠️ 부분 관측 - 가구주관계코드 = 03(미혼 자녀) & 만연령 ≤ 18인 가구원이 있으면 가구 단위로 자녀_청소년있음 = 1 (부모 행에만 표시). 12세 이하 자녀는 표본에 없어 영유아·아동 자녀 여부는 관측 불가

정책 생성 기준 — 자녀_영유아, 자녀_아동, 자녀_청소년 (0/1/2): 자녀여부=2인 정책에서 생애주기 태그에 해당 단계가 있으면 2; 미성년 태그가 없어 나이 미상이면 셋 다 2(관대). 여러 개가 2이면 OR(그중 한 연령대 자녀만 있으면 됨). 분포(2): 영유아 104, 아동 122, 청소년 117.

매칭 규칙 — 자녀_청소년=2: 자녀_청소년있음=1 → 1, 자녀있음=0 → 0, 그 외 NaN. 자녀_영유아·아동=2: 자녀있음=0 → 0, 그 외 NaN(미관측). 연령 범위가 13~18과 겹치는 자녀 대상 정책도 같은 방식.

15. 한부모

사회조사 생성 기준 ⚠️ 근사(과소) - 가구주 혼인상태코드 ∈ {1 미혼, 3 별거, 4 이혼, 5 사별} (무배우) & 가구 내 관계코드 03·만 18세 이하 자녀 존재 → 가구 전원 한부모_근사 = 1 (456명 ≈ 170가구, 1.4%) - 12세 이하 자녀 미관측으로 실제(가계동향 기준 1.85%)의 약 절반만 포착. 사회조사 판정은 "최소 이만큼"의 하한선

정책 생성 기준 — 한부모 (0/1/2): 결합 태그 '한부모·조손' 단독 또는 서비스명 한부모|조손이면 전용 후보 → 원문·서비스명 키워드 한부모|모자가정|부자가정으로 한부모 측 지정. 어느 쪽 키워드도 없으면 한부모·조손 양쪽 2(OR). 전용 10개, 양쪽 2인 4개.

매칭 규칙 — 한부모=2: 한부모_근사=1 → 1, 그 외 NaN(0을 확정 배제로 쓰지 않음 — 미관측 어린 자녀 가능성).

16. 조손

사회조사 생성 기준 ⚠️ 근사(과소) — 가구 내 관계코드 05(손주)·만 18세 이하 존재 & 중간세대(관계코드 03·04) 부재 → 조손_근사 = 1 (45명, 0.1%; 가계동향 0.30%의 약 1/3).

정책 생성 기준 — 조손 (0/1/2): 위 결합 태그 분리에서 키워드 조손|손자녀 → 조손 측. 전용 5개.

매칭 규칙 — 조손=2: 조손_근사=1 → 1, 그 외 NaN.

17. 다문화 / 탈북민

사회조사 생성 기준 ⚠️ 부분 - 현재국적코드 (1 대한민국 / 2 외국) → 외국국적 1/0 (556명, 2.0%) → 다문화_근사 = 외국국적. 귀화한 결혼이민자·다문화가족 자녀(국적 한국)는 포착 불가 - 탈북민: 관련 문항 전무, 국적도 대한민국이라 식별 불가 → 앱 입력

정책 생성 기준 — 다문화, 탈북민 (0/1/2): 결합 태그 '다문화·탈북민' 단독 또는 서비스명 키워드면 전용 후보 → 다문화|결혼이민 / 탈북|북한이탈로 분리, 둘 다 없으면 양쪽 2(OR). 전용 다문화 10개, 탈북민 15개, 양쪽 2인 4개.

매칭 규칙 — 다문화=2: 외국국적=1 → 1, 그 외 NaN. 탈북민=2: 항상 NaN.

18. 군인·병역

사회조사 생성 기준 ⚠️ 부분 — 직업대분류코드 = 'A'(군인) → 직업군인 1/0 (58명, 0.2%). 현역 직업군인만 식별, 제대군인·병역의무자는 불가.

정책 생성 기준 — 군인병역 (0/1/2): 원문·서비스명에 제대군인|병역|현역|군인(?!연금) → 2 (23개). 기초연금·장애인연금의 "군인연금 수급자 제외"처럼 배제 조항이 걸린 사례가 섞여 있어 검수 대상. 국가유공자·보훈은 별도 변수(§20).

매칭 규칙 — 군인병역=2: 직업군인=1 → 1, 그 외 NaN.

19. 질병·환자

사회조사 생성 기준 ⚠️ 근사 — 질환명 문항 없음. 활동제약_있음(§4 보조 변수)이 기능 제한의 근사. 자격 판정에는 사용하지 않고 NaN 처리.

정책 생성 기준 — 질병유무 (0/1/2) + 질병명_상세 - 원문·서비스명에 환자|질환|질병|암|치매|희귀 → 2 (94개) - 질병명_상세: 12개 유형 키워드로 분류해 쉼표 나열 — 암 / 치매 / 희귀·중증난치질환 / 정신질환·우울 / 결핵 / 난임 / 만성질환(고혈압·당뇨) / 산재·업무상재해 / 감염병·격리 / 노인성질환(장기요양) / 선천성·소아질환 / 일반상병(입원·치료중). 어디에도 안 잡히면 '기타·미분류'(33개, 오탐 후보) - 앱 입력 문항(질환 유형 체크리스트 + 산정특례·장기요양등급·산재 승인 여부)과 1:1 대응

매칭 규칙 — 질병유무=2: 사회조사에서는 NaN(판정 불가). 앱에서는 사용자가 선택한 유형이 질병명_상세에 있으면 통과, 질환 없음이면 제외, 미응답이면 유지.

규칙 엔진은 이 축이 2인 정책에서 해당 조건을 NaN으로 두므로, 다른 조건이 0이 아니면 정책 자격은 NaN(불명)이 된다. 또한 변수화되지 않은 특수 신분(서비스명에 위탁|입양|보호종료|자립준비|북한이탈|새터민|사할린|원폭|고엽제|한센|위안부|결핵|난임|산재|학교 밖|가출|노숙|범죄피해|성폭력|가정폭력|학대|수형|출소|재소|의사상자|참전|유공)도 NaN 처리한다.

부록 B. Tier 분류

  • Tier A (완전 판정, 95개): 모든 조건이 사회조사 변수로 판정되고(NaN 0%) proxy 미사용
  • Tier B (근사 판정, 336개): 소득 %·수급근사·한부모/조손/다문화 근사·지역유형 근사 중 하나 이상 사용 또는 일부 NaN
  • 판정 불가 (30개): 특수 신분 등으로 전 표본 NaN
