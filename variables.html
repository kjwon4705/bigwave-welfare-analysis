1. 변수 체계 개요

자유 텍스트로만 존재하던 지원조건(지원대상 상세·선정기준)을 매칭 엔진이 사용할 수 있는 변수로 인코딩했다. 범주형 변수는 공통 코딩 체계를 따른다:

코드 의미
0 해당 조건·대상이면 받을 수 없음 (배제)
1 해당 조건·대상과 무관하게 받을 수 있음 (기본값)
2 해당 조건·대상이어야만 받을 수 있음 (전용/필수)
  • 같은 축에서 여러 변수가 2인 경우는 OR 그룹(그중 하나만 충족하면 됨)으로 해석한다.
  • 판정 불명확 시 제외하지 않는 관대한 필터 원칙을 따른다.
